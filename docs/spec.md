## 1. 概要

個人用家計簿アプリの CLI（`kakeibo`）の仕様を定める。
取引の登録・一覧・編集・削除、月次集計、予算の設定と消費進捗率の表示、定型取引による入力の省略を扱う。
REST API の仕様は [api-spec.md](api-spec.md)、設計判断の背景は [adr.md](adr.md) にある。

---

## 2. 用語集

| 用語 | 意味 |
|------|------|
| 取引 | 収入・支出 1 件の記録 |
| カテゴリ | 取引の分類。識別子で指定する（3-2 参照） |
| 予算 | 支出の上限金額。月全体またはカテゴリ別に設定する |
| 消費進捗率 | 基準値に対する当月の支出の割合。基準値は予算か昨月の実績支出 |
| 収支 | 収入の合計から支出の合計を引いた額 |
| 定型取引 | 名称・金額・カテゴリが毎回同じ取引のひな形。コマンド名は `preset` |
| キー | 定型取引の識別子 |
| user_id | データの持ち主の識別子。Google アカウントの `sub` クレーム（CLI では `'local'`） |

## 4. コマンド仕様

### 4-1. 取引の追加

```bash
kakeibo add --name "UberEats" --amount 1500 --category food
kakeibo add --name "UberEats" --amount 1500 --category food --date 2025-04-30
kakeibo add --name "UberEats" --amount 1500 --category food --memo "夕食"
kakeibo add --preset commute                                  # 定型取引（4-8）の値で登録
kakeibo add --preset commute --amount 320 --memo "片道のみ"    # 一部の値だけ上書き
```

| オプション | 短縮形 | 必須 | デフォルト |
|-----------|--------|------|-----------|
| `--name` | `-n` | ✓ | - |
| `--amount` | `-a` | ✓ | - |
| `--category` | `-c` | ✓ | - |
| `--date` | `-d` | - | 実行日 |
| `--memo` | `-m` | - | なし |
| `--preset` | `-p` | - | なし |

`--preset` を指定した場合は `--name` / `--amount` / `--category` も省略でき、省略した項目には定型取引の値を使う。

### 4-2. 取引の一覧表示

```bash
kakeibo list                     # 当月の全取引
kakeibo list --month 2025-04     # 指定月の全取引
kakeibo list --category food     # 当月をカテゴリ絞り込み
```

### 4-3. 取引の編集

```bash
kakeibo edit 3 --amount 2000        # ID=3の金額を上書き
kakeibo edit 3 --memo "新しいメモ"  # ID=3のメモを上書き
```

指定したIDの任意フィールドを上書きする。複数フィールドの同時指定も可。

### 4-4. 取引の削除

```bash
kakeibo delete 3    # ID=3の取引を削除
```

### 4-5. 月次集計

```bash
kakeibo summary                  # 当月
kakeibo summary --month 2025-04  # 指定月
kakeibo summary --by-category    # カテゴリ別（--month と併用可）
```

#### 出力例

```
== 2025年04月 集計 ==

収入
  収入          200,000円

支出
  食費           32,000円
  固定費         60,000円
  交通費          8,000円
  ...
  ─────────────────────
  合計          120,000円

収支         +80,000円
```

### 4-6. 消費進捗率

```bash
kakeibo progress                             # 月全体 + カテゴリ別（予算対比、デフォルト）
kakeibo progress --total                     # 月全体のみ（予算対比）
kakeibo progress --by-category              # カテゴリ別のみ（予算対比）
kakeibo progress --last-month               # 月全体 + カテゴリ別（昨月実績対比）
kakeibo progress --last-month --total       # 月全体のみ（昨月実績対比）
kakeibo progress --last-month --by-category # カテゴリ別のみ（昨月実績対比）
```

#### 表示モード

| モード | 基準値 | 基準値が無効な場合の挙動 |
|--------|--------|--------------------------|
| デフォルト（予算対比） | `budgets` テーブルの設定値 | 予算未設定時はエラーを表示して終了 |
| `--last-month`（昨月対比） | 昨月の実績支出額 | 昨月の支出データが 0（取引なし・収入のみ）の場合は N/A を表示する |

#### 予算対比の出力例

### 4-7. 予算の設定

```bash
kakeibo budget set --total 150000             # 月全体の上限
kakeibo budget set --category food 40000      # カテゴリ別上限
kakeibo budget show                           # 現在の予算設定を表示
```

予算は月を指定しない場合、全月共通のデフォルト予算として登録される。

### 4-8. 定型取引

名称・金額・カテゴリが毎回同じ取引（出社時の交通費など）を、キー付きのひな形として登録しておく。

```bash
kakeibo preset add commute --name "通勤（本社）" --amount 640 --category transport
kakeibo preset edit commute --amount 700
kakeibo preset list
kakeibo preset delete commute
```

| 引数・オプション | 短縮形 | `preset add` | `preset edit` |
|-----------------|--------|--------------|---------------|
| `<KEY>` | - | ✓ | ✓ |
| `--name` | `-n` | ✓ | - |
| `--amount` | `-a` | ✓ | - |
| `--category` | `-c` | ✓ | - |
| `--memo` | `-m` | - | - |

✓ は必須を表す。`preset edit` は指定した項目だけを上書きする。

#### `preset list` の出力例

```
キー               名称           金額    カテゴリ
──────────────────────────────────────────────
commute            通勤（本社）    700円  交通費
commute-shinagawa  通勤（品川）    820円  交通費
```

`add --preset` は定型取引の値をコピーして取引を登録する。そのため、定型取引を編集・削除しても登録済みの取引は変わらない。定型取引は現在の金額だけを持ち、金額の履歴は持たない。

#### 通勤交通費の運用例

| 場面 | 操作 |
|------|------|
| 通常のオフィスに出社した | `kakeibo add --preset commute` |
| 運賃改定・引越しで金額が変わった | `kakeibo preset edit commute --amount 700`（以降の登録から反映） |
| 別のオフィスに繰り返し行く | オフィスごとに定型取引を追加する（例: `commute-shinagawa`） |
| 別のオフィスに一度だけ行く | 定型取引を作らず、通常の `add` で登録する |
| 片道だけなど金額が違う日 | `kakeibo add --preset commute --amount 320` |
| 運賃改定前の日付をあとから登録する | `kakeibo add --preset commute --date <日付> --amount <旧運賃>` |

キーは将来の Claude 連携（MCP）で、Claude が定型取引を選ぶ手がかりにもなる。通常のオフィスは `commute`、それ以外は `commute-<場所>` とすることを推奨する。

## 5. データ設計

### transactions テーブル

| カラム | 型 | 備考 |
|-------|-----|------|
| id | INTEGER PRIMARY KEY | 自動採番、削除後は欠番 |
| user_id | TEXT NOT NULL | 用語集を参照 |
| name | TEXT NOT NULL | 名称 |
| amount | INTEGER NOT NULL | 金額（円、正の整数） |
| date | TEXT NOT NULL | ISO 8601形式 YYYY-MM-DD |
| category | TEXT NOT NULL | カテゴリ識別子 |
| memo | TEXT | メモ（任意） |
| created_at | TEXT NOT NULL | 登録日時 |

### budgets テーブル

| カラム | 型 | 備考 |
|-------|-----|------|
| id | INTEGER PRIMARY KEY | 自動採番 |
| user_id | TEXT NOT NULL | 用語集を参照 |
| month | TEXT | YYYY-MM 形式。NULL の場合は全月共通のデフォルト予算 |
| category | TEXT | NULL の場合は月全体の予算 |
| amount | INTEGER NOT NULL | 上限金額（円） |

### presets テーブル

| カラム | 型 | 備考 |
|-------|-----|------|
| id | INTEGER PRIMARY KEY | 自動採番 |
| user_id | TEXT NOT NULL | 用語集を参照 |
| key | TEXT NOT NULL | 定型取引の識別子。`(user_id, key)` で一意 |
| name | TEXT NOT NULL | 名称 |
| amount | INTEGER NOT NULL | 金額（円、正の整数） |
| category | TEXT NOT NULL | カテゴリ識別子 |
| memo | TEXT | メモ（任意） |

## 6. 制約・境界条件

- 金額は正の整数のみ（小数点以下不可、0以下不可）
- 日付の入力フォーマットは `YYYY-MM-DD` のみ受け付ける
- IDは削除後に欠番になる（採番のやり直しはしない）
- list コマンドの件数上限は設けない（全件表示）
- カテゴリは上記一覧の識別子のみ受け付ける（任意文字列は不可）
- 定型取引のキーは英小文字・数字・ハイフンのみ、1〜32 文字とする
- 既存のキーで `preset add` した場合はエラーとする
- 存在しないキーを `add --preset`・`preset edit`・`preset delete` に指定した場合はエラーとする
- 定型取引の値と、`add --preset` で上書きした値にも、取引と同じ制約を適用する
